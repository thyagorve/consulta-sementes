INFINITY STOCK - V11.9 DESEMPENHO E CONSISTÊNCIA
Data: 17/09/2026

Objetivo
- Reduzir o peso percebido após a evolução do modo offline.
- Evitar trabalho em segundo plano desnecessário em cada navegação.
- Fazer PC e celular convergirem mais rapidamente para o mesmo estado do servidor.

Ajustes principais
1. Offline progressivo
   - Não pré-carrega mais várias telas, APIs e CDNs em toda navegação.
   - A tela realmente visitada é armazenada para uso offline.
   - Cada tela adicional passa a ficar disponível offline depois de ser visitada online.

2. Snapshots sem bloquear a tela
   - Respostas usadas no offline são gravadas no IndexedDB depois de serem entregues à interface.
   - Apenas APIs realmente necessárias para consulta offline são persistidas.
   - Pollings e endpoints auxiliares não ficam mais gravando IndexedDB o tempo todo.

3. Referência offline pesada
   - Atualização completa da referência passou de 45 segundos para até 10 minutos.
   - Só é preparada em telas operacionais e quando o navegador está ocioso.
   - Após sincronização, respeita o throttle em vez de baixar tudo imediatamente.

4. Solicitações
   - Removido download completo dos cards a cada 30 segundos.
   - Mantida verificação leve de versão a cada 12 segundos.
   - A lista completa só é recarregada quando a versão realmente muda.
   - Requisições duplicadas de carregarCards são deduplicadas.

5. Kanban
   - Verificação leve de versão a cada 15 segundos quando a tela está visível.
   - Só recarrega o Kanban quando o servidor informa alteração.
   - Evita requisições completas concorrentes.
   - Versão do servidor agora considera cards, expedições avulsas e ajustes de carga.

6. Dashboard
   - Ao voltar para a aba depois de 45s, atualiza uma vez para evitar número antigo.
   - Não adiciona polling pesado contínuo.

7. Fonte dos dados
   - Se uma API cair para snapshot local, aparece aviso persistente:
     "DADOS LOCAIS: aguardando confirmação do servidor".
   - Quando o servidor responde novamente, o aviso desaparece.
   - Isso evita confundir snapshot local com dado online oficial.

Service Worker
- Cache: infinity-stock-v11-shell-10
- offline-sync.js: v=11.9-performance

Banco
- Nenhuma migration nova nesta versão.
- Mantém a migration 0044 da V11.8.

Deploy
1. Fazer backup.
2. Subir a versão.
3. python manage.py migrate (seguro; aplica apenas pendências existentes)
4. python manage.py collectstatic --noinput
5. Reiniciar/redeploy da aplicação.
6. Abrir online e fazer Ctrl+F5 uma vez.

Teste recomendado
- Abrir Kanban no PC e no celular.
- Confirmar que ambos estão sem o aviso "DADOS LOCAIS".
- Criar/ajustar uma carga em um dispositivo.
- Em até ~15s o outro Kanban deve atualizar sem F5.
- Navegar entre Solicitações, Kanban, Dashboard e Estoque e comparar a velocidade.
- Depois de visitar uma tela online, desligar a internet e testar a reabertura daquela tela.
