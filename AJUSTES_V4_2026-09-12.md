# Ajustes V4 - 2026-09-12

## Gerenciador de playlists
- Ao selecionar um cliente existente no cadastro unificado, o sistema consulta os dados atuais do cliente.
- O usuário IPTV (`login_externo`) e a senha IPTV (`senha_leitura`) são preenchidos automaticamente.
- As credenciais são preparadas simultaneamente nos modos Xtream Code e Parceria, permitindo trocar o modo de acesso sem selecionar o cliente novamente.
- Se o cliente não tiver credenciais cadastradas, a interface informa isso sem impedir o restante do cadastro.
