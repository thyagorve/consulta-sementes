V11.3.2 - CORREÇÃO FILA / API SYNC 400

Problema corrigido:
- Em produção, operações compostas antigas eram enviadas com quantidade=null.
- O SyncOperationInputSerializer tinha quantidade opcional, porém não aceitava null.
- O POST /api/sync/ respondia 400 e o lote inteiro da fila permanecia pendente.

Correções:
1. quantidade agora aceita null no serializer de sincronização.
2. O cliente remove campos opcionais nulos antes de enviar a fila.
3. Erros HTTP de sync agora registram no console o corpo retornado pelo servidor.
4. Cache do Service Worker atualizado para shell-4.
5. offline-sync.js recebeu nova versão de query string para forçar atualização em produção.

Sem migration nova.
