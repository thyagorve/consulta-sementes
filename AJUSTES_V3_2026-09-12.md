# Ajustes V3 - 12/09/2026

## Gerenciador de playlists
- Dispositivo e lista passaram a ser apresentados como um único cadastro visual.
- Não existe mais ação de "Nova lista" por dispositivo na tela principal.
- Ao editar o cadastro, a mesma lista principal é criada/atualizada.
- Se nenhum dado de lista for preenchido, o cadastro fica como "Somente dispositivo".
- Modos de acesso disponíveis: Lista M3U, Xtream Code e Parceria.
- Lista M3U: URL M3U, URL EPG opcional e senha de edição opcional.
- Xtream Code: DNS/servidor, usuário e senha.
- Parceria: usuário, senha e código do servidor.
- Não foi adicionado campo de vencimento.
- Dados adicionais de M3U (EPG/senha de edição) são armazenados no JSON existente da PlaylistRemota, portanto não exige nova migration.
- O backend converte os novos modos para os formatos já entendidos pelos providers (URL/código) na hora de publicar.

## Lista de clientes
- Clientes com cadastro no Gerenciador de playlists recebem um ícone destacado ao lado do nome.
- Ao clicar no ícone, abre o Gerenciador de playlists já filtrado pelo nome do cliente.
- No painel de ações expandido, o botão também muda de "App" para "Playlist" quando o cliente já possui cadastro.
- O indicador funciona tanto no carregamento normal quanto nos resultados carregados por AJAX.

## Correções anteriores mantidas
- Histórico financeiro carregado por cliente, até 5 registros para cada cliente.
- Recarregamento automático após renovação concluída.
- Recarregamento automático após alteração de saldo.
- Fluxo de renovação compartilhada com apenas dois botões por etapa.
