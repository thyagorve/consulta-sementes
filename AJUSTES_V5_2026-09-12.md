# Ajustes V5 - 12/09/2026

## Gerenciador de playlists

- Corrigida a configuração que estava identificada como **Device Key padrão**.
- A configuração agora é **Código de proteção das listas** e serve exclusivamente como PIN de proteção.
- A Device Key continua sendo informada no cadastro do dispositivo quando o aplicativo exigir.
- Novas listas recebem automaticamente o código de proteção configurado, sem exibir esse código no cadastro do cliente.
- Listas já protegidas preservam o PIN atual para evitar perda de acesso remoto.
- Ao editar um cadastro que possui lista protegida, o código de proteção é solicitado novamente e validado no backend.
- O PIN não é devolvido automaticamente pelo endpoint de detalhes.
- A migration `0095_configuracao_codigo_protecao_playlist.py` copia o valor da antiga configuração de Key para o novo campo de proteção, preservando o valor já configurado.

## Transições

- Adicionada transição suave de entrada e saída em todas as páginas principais que usam `base.html`.
- Adicionada barra fina de progresso durante navegação interna.
- Adicionada transição de entrada/saída também nas telas standalone de login, portal do cliente e jogos do dia.
- Respeitado `prefers-reduced-motion` para acessibilidade.

## Implantação

Após atualizar o projeto, executar:

```bash
python manage.py migrate
python manage.py check
```
