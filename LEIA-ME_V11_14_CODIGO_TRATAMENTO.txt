INFINITY STOCK V11.14 - SINCRONIA CÓDIGO / TRATAMENTO
Data: 19/09/2026

Objetivo
- Corrigir inconsistência entre Código do Produto e Tratamento nas telas Editar e Transferir estoque.

Regras
1. Ao alterar o CÓDIGO:
   - se o código existir em Produto, Cultivar/Tratamento/Peneira/Categoria/Espécie acompanham o cadastro.
   - se o código não estiver cadastrado, os dados técnicos escolhidos manualmente são preservados.

2. Ao alterar CULTIVAR ou TRATAMENTO sem trocar manualmente o código:
   - se houver exatamente um Produto ativo para a combinação, o código muda automaticamente para esse Produto.
   - se não houver Produto cadastrado para a combinação, o código antigo é limpo e a nova classificação é preservada.
   - se houver mais de um Produto possível, o código antigo é limpo e a tela pede o código correto.

3. Transferência pela fila rápida/offline:
   - passa a enviar e aplicar Código, Cultivar, Tratamento, Peneira, Categoria, Espécie, Empresa, Cliente, Peso e Embalagem.
   - antes a fila levava basicamente endereço/quantidade e podia recriar o destino com a classificação antiga.

Banco
- Nenhuma migration nova.

Após deploy
- collectstatic/rebuild conforme fluxo do servidor.
- Ctrl+F5 uma vez para expulsar HTML/JS antigo do cache.
